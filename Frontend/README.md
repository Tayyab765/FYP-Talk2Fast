# Talk2FAST Admission Assistant

React frontend for the Talk2FAST Admission Assistant — login, signup, and student dashboard.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```

## Pages

- **Login** — `/login` — University email + password, “Keep me logged in”, Forgot password, Create account link
- **Signup** — `/signup` — Full name, University email, Password, Confirm password, Create Student Account
- **Dashboard** — `/dashboard` — Welcome section, 3 feature cards (AI Assistant, Mock Test, Recommendations), Performance Summary bar chart, Overall Readiness (78% circle)

## Tech

- React 18 + Vite
- React Router 6
- CSS (variables, no UI library)
